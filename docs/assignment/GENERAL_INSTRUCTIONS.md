# Technical Interview Instructions

## Role
**Python Developer - ETL & Data Engineering**

Responsibilities:
- ETL processes based on Python
- Integration with internal/external APIs
- Using LLMs to improve ETL processes
- Document data scraping from portals (metadata, content)
- Working with financial data
- Documentation

## Interview Structure

### Tasks:
- **Task 1**: ETL Pipeline 
- **Task 2**: API Integration 
- **Task 3**: Document Scraping 
- **Task 4**: LLM-assisted Data Extraction
- **Task 5**: End-to-End Mini Project 

## Technical Environment

**Python version:** 3.9+

**Code Style:** Object-Oriented Programming required
- Use classes and objects for all major components
- Apply SOLID principles where appropriate
- Avoid procedural/functional-only approaches

**Allowed libraries:**
- Python standard library
- pandas, numpy
- requests, beautifulsoup4, xml.etree.ElementTree
- sqlite3
- flask/fastapi (for API tasks)
- anthropic, openai (for LLM tasks)
- Other popular libraries

**IDE/Editor:** VSCode, PyCharm

## Evaluation Criteria

### 1. Code Quality (25%)
- Readable and maintainable code
- Proper structure and organization
- Naming conventions
- DRY principle

### 2. Functionality (25%)
- Does it solve the task correctly?
- Are edge cases handled?
- Performance considerations

### 3. Error Handling (20%)
- Robust error handling
- Proper error messages

### 4. Documentation (15%)
- Docstrings
- Comments where necessary
- README files

### 5. Best Practices (15%)
- Logging
- Configuration management
- Security considerations
- Testing (where applicable)

## Tips

**DO:**
- Write production-ready code
- Add logging

**DON'T:**
- Don't neglect error handling
- Don't hardcode
